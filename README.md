# React Playground

A modern React + TypeScript admin dashboard demonstrating reusable architecture, authentication patterns and production-ready frontend practices.

The project emphasizes maintainability, performance and developer experience.

## Features

- Authentication flow (Login & Register)
- Custom ACL system
- Reusable UI component library
- State management with Zustand
- Server state management with TanStack Query
- Form handling with React Hook Form
- Schema validation with Zod
- Progressive Web App (PWA)
- Multi-language support (i18n)
- Responsive design
- Encrypted local storage
- Custom SVG support
- Component testing with Vitest
- React Router v7
- Socket.IO integration
- TypeScript support

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router v7
- Zustand
- TanStack Query
- React Hook Form
- Zod
- Tailwind CSS
- Vitest
- i18next
- Socket.IO

## Architecture

The project follows a file-type based architecture with clear separation of concerns.

It demonstrates how reusable components, hooks, stores and services can be organized to create scalable frontend applications.

## Performance

- Client-side caching with TanStack Query
- PWA support
- Optimized state management
- Reusable components and hooks

## Testing

UI components are covered with tests using Vitest and Testing Library.
